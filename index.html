Pusat Panduan

Temukan cara instalasi, pengaturan awal, dan jawaban atas pertanyaan umum.

Pilih menu "Literatur", kemudian klik ikon "+" untuk membuat struktur folder baru (misalnya berdasarkan model alat berat). Anda dapat memindahkan, mengganti nama, atau menghapus file dengan menahan (long press) pada file tersebut untuk memunculkan menu konteks manajemen file.
Setelah selesai mengisi seluruh langkah JSEA beserta mitigasinya, pastikan bagian "Tanda Tangan" telah diisi. Klik tombol "Export", lalu pilih "Format Excel Corporate". Sistem secara otomatis akan memisahkan penomoran (misal: 1.1) dengan deskripsi dalam kolom berbeda sesuai format korporat.
Masuk ke menu "Pengaturan Watermark". Centang opsi "Pertahankan Metadata (Auto)". Dengan pengaturan ini, nama unit, lokasi, dan jenis temuan akan otomatis disalin ke foto-foto berikutnya tanpa perlu mengetik ulang, sangat mempercepat inspeksi massal.
